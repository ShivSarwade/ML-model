## 📖 Overview

Predicting classroom attendance is historically difficult because it relies on non-linear scheduling rules. Students don't skip class randomly; they skip based on complex rules like *"Is it the week before an exam?"*, *"Is this an 8:00 AM class the day after a holiday?"*, or *"Have they already skipped the last two classes?"*

This project solves this by framing the problem in two ways:
1. **Classification:** Predicts the "Attendance Risk Band" (`Low`, `Medium`, `High`).
2. **Regression:** Predicts the exact percentage of students who will attend (`0% - 100%`).

We engineered custom features (like rolling momentum and holiday adjacency) and evaluated 12 distinct machine learning algorithms. The final deployment leverages **XGBoost and Naive Bayes**, achieving a realistic accuracy ceiling of **~52%** due to the extreme inherent randomness (18.66 standard deviation) of human classroom attendance.

## 🚀 How to Run the Project from Scratch

This project is fully automated. If you clone this repository and only have the `data/raw/attendance_raw.csv` file, follow these steps to rebuild the entire pipeline:

### 1. Install Dependencies
Open your terminal/command prompt and install the required Python libraries:
```bash
pip install -r requirements.txt
```

### 2. Run the Master Orchestrator Pipeline
Instead of running files one by one, we have built a master orchestrator. This single command will automatically clean the data, engineer all advanced temporal features, calculate metrics, and train all 12 Classification and Regression algorithms!

```bash
cd src
python run_pipeline.py
```
*(Wait a few seconds while it trains the models. You will see a comprehensive report printed to your console with Accuracy, F1, Precision, Recall, ROC-AUC, MAE, and R² metrics).*

### 3. Launch the Interactive Dashboard
Once the models are trained, you can interact with the live forecasting UI!

```bash
cd ..
streamlit run dashboard/app.py
```
This will open a beautiful web application in your browser where you can tweak scheduling parameters (like "Time of Day" or "Week Number") to instantly see the AI's attendance prediction.

## 🧠 Core Methodology & Features

To mathematically map the attendance behavior despite the extreme random noise, we strictly engineered features using historical `.shift(1)` logic. Key features include:

- **Rolling Momentum (`Rolling_Avg_3`):** The exact attendance average of the previous 3 lectures for that specific cohort.
- **Time of Day Clustering:** Differentiating between Morning and Afternoon drop-offs.
- **Holiday Adjacency:** Tracking "Days since last holiday" to catch post-holiday attendance slumps.
- **Exam Proximity:** Flagging lectures that occur immediately before internal test weeks.

For full architectural details, please read the `documentation/methodology.md` and the `Final_Report.md` files.
