# 02 - Exploratory Data Analysis (EDA)

## Objective
This folder contains our visual analysis of the historical attendance data to uncover hidden patterns that will inform our algorithm.

## What This Achieves
- Checks for class imbalances (e.g., is the average attendance always 90%, or is it highly variable?).
- Identifies macro-trends: Do 8:30 AM classes suffer from poor attendance? Does Friday afternoon attendance drop?
- Analyzes the statistical impact of variables like `Weather`, `Internal_Test_Week`, and `Subject` on overall attendance rates.
- Ensures the data has enough variation to train a robust Machine Learning model.
