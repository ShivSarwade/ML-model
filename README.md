# Classroom Attendance Prediction

This is an end-to-end Machine Learning pipeline for predicting classroom attendance based on academic schedules, student history, and environmental factors.

## How to Run the Project

This project has been fully automated. You do not need to manually install dependencies or open individual notebooks.

Follow these exact steps from a completely fresh download to set up the environment, run the machine learning notebooks, and launch the prediction dashboard.

### 1. Run the Machine Learning Pipeline

Open your terminal in this root directory (where `run_pipeline.py` is located) and run this single command:

```bash
python run_pipeline.py
```

**What this script does automatically in the background:**
1. **Creates a virtual environment** (`venv`) inside the `attendance_prediction` folder.
2. **Installs all dependencies** from `requirements.txt` (including Streamlit, XGBoost, Scikit-learn, etc.).
3. **Cleans old artifacts** ensuring a completely fresh start.
4. **Executes all 17 Jupyter Notebooks sequentially** inside the `attendance_prediction/jupiter books/` folder.
5. **Exports all trained models and metadata** natively via the notebooks directly into the `attendance_prediction/deployment_assets/` folder.

Just wait a couple of minutes for the terminal to print **"Pipeline Finished Successfully!"**.

### 2. Launch the Streamlit App

Once the models are generated by the pipeline, you can launch the beautiful interactive web dashboard. 

Navigate to the `attendance_prediction` folder and use the virtual environment's Streamlit executable to launch the app:

```bash
cd attendance_prediction
.\venv\Scripts\streamlit run app.py
```

The app will now open automatically in your browser at `http://localhost:8501`.

## Troubleshooting

- **"Prediction Error: The feature names should match..."**: This means your `.pkl` files are out of sync with the data. Simply run `python run_pipeline.py` again to cleanly rebuild all artifacts.
- **Missing Models**: Ensure the pipeline script finishes completely without interruption.
